# Work Session 4 solution files

This folder contains the assignment split into Part A–D answer files, a separate final discussion, figures, the dataset, and a runnable analysis script.

Open `work_session_4_solution.ipynb` for the sectioned notebook version. Its first code cell reruns the full analysis; written answers and plots appear under their corresponding parts.

## Run

Install dependencies with `python -m pip install -r requirements.txt`, then run `python solution.py` from this folder. The script regenerates `results.md` and the figures in this folder.

## Contents

- `part_a_inspection.md` — data inspection and leakage risks
- `part_b_leakage.md` — split strategies, duplicate leakage, and preprocessing leakage
- `part_c_overfitting.md` — tree and polynomial complexity
- `part_d_generalization.md` — cohort encoding, feature selection, regularization, and final model table
- `final_discussion.md` — responses to the six discussion questions
- `figures/` — generated plots
- `solution.py` — complete runnable analysis
- `hybrid_student_performance_1200.csv` — source dataset copy
